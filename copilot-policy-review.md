# GitHub Copilot Interaction Data Policy Review

**Date:** 2026-04-21
**Policy Effective Date:** April 24, 2026

## Summary

GitHub has announced a policy change: starting April 24, 2026, GitHub Copilot interaction data will be used for AI model training unless users explicitly opt out.

## What This Means

- **Interaction data** includes prompts, suggestions, and feedback provided during Copilot sessions.
- This data will be used to improve GitHub's AI models.
- This is an **opt-out** policy — it is enabled by default unless you take action.

## Action Required

To opt out:
1. Navigate to your GitHub account settings.
2. Find the **Copilot** or **Privacy** section.
3. Locate the setting for AI model training / interaction data.
4. Disable or opt out of the data sharing option.

## Impact Assessment

| Concern | Detail |
|---|---|
| Data collected | Prompts, code completions, feedback ratings |
| Purpose | Training GitHub's AI/Copilot models |
| Default | Opted **in** unless changed |
| Who is affected | All GitHub Copilot users |

## Recommendation

- **Personal accounts:** Review and opt out if you do not want your interaction data used for training.
- **Organizations:** Organization admins should review enterprise Copilot settings and enforce a policy for members.
- **Open-source contributors:** Be aware that code suggestions generated from your repositories may be part of interaction data if Copilot is used in those contexts.
